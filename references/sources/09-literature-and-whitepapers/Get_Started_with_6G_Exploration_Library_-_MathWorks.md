### Get Started with 6G Exploration Library

**R2026b** Learn the basics of the 6G Exploration Library 6G Exploration Library for 5G Toolbox™ enables you to explore, model, and test candidate 6G waveforms and technologies. The tutorials, links, and videos featured here help you learn the basics of modeling 6G with MATLAB ® and give background information about 6G technology. To use this functionality, download and install the [6G Exploration Library for 5G Toolbox](<https://www.mathworks.com/matlabcentral/fileexchange/157771>) add-on.
