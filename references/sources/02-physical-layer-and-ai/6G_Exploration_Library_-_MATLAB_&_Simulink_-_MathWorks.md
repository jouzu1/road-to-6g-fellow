### 6G Exploration Library

**R2026b** Candidate 6G waveform generation and simulations 6G Exploration Library for 5G Toolbox™ enables you to explore, model, and test candidate 6G waveforms and technologies. With the library, you can: * Model waveforms with modulation schemes, bandwidths, and subcarrier spacings beyond the possible values stipulated by 5G NR. * Explore the impact of hardware impairments at sub-THz carrier frequencies. * Model integrated sensing and communication (ISAC) systems and reconfigurable intelligent surfaces. * Use the ISAC channel model from 3GPP TR 38.901 Section 7.9 in a 5G-link level simulation. * Analyze the performance of 5G and 6G networks using digital twin techniques. * Replace conventional channel estimation, equalization, and symbol demodulation with an AI-native fully convolutional receiver. * Integrate a trained PyTorch ® network with MATLAB ®-based data generation to simulate an AI-native air interface. To use this functionality, download and install the [6G Exploration Library for 5G Toolbox](<https://www.mathworks.com/matlabcentral/fileexchange/157771>) add-on.
