### Get Started with 6G Exploration Library

**R2026b** _Since R2024a_ This example uses: * [6G Exploration Library for 5G Toolbox](<about:invalid#zCSafez>) [6G Exploration Library for 5G Toolbox](<https://www.mathworks.com/help/5g/6g-exploration-library.html>) Open in MATLAB Online Copy Code Copy Command 6G Exploration Library for 5G Toolbox™ enables you to explore, model, and test candidate 6G waveforms and technologies. The library extends the capability of the 5G Toolbox: * You can use the [pre6GCarrierConfig](<https://www.mathworks.com/help/5g/ref/pre6gcarrierconfig.html>) object to set a subcarrier spacing greater than 960 kHz (the maximum specified in TS 38.211 Table 4.2-1 [\\[1\\]](<https://www.mathworks.com/help/5g/ug/get-started-with-6g-exploration-library.html#mw_rtc_GetStartedWith6GExplorationLibraryExample_M_C2C627CE>)). * You can use the pre6GCarrierConfig and [pre6GPhysicalChannelConfig](<https://www.mathworks.com/help/5g/ref/pre6gphysicalchannelconfig.html>) objects to create resource grids and resource allocations with more than 275 resource blocks (the maximum specified in TS 38.331 Section 6.3.2 [\\[2\\]](<https://www.mathworks.com/help/5g/ug/get-started-with-6g-exploration-library.html#mw_rtc_GetStartedWith6GExplorationLibraryExample_M_5605E5B7>)). * You can use the pre6GPhysicalChannelConfig object to specify a modulation scheme of 4096-QAM (beyond the limit of 1024-QAM specified in TS 38.211 Section 5.1 [\\[1\\]](<https://www.mathworks.com/help/5g/ug/get-started-with-6g-exploration-library.html#mw_rtc_GetStartedWith6GExplorationLibraryExample_M_C2C627CE>)). This example shows how to use these extended capabilities to explore 6G candidate waveforms, and provides references for further exploration.

##### Subcarrier Spacings Greater Than 960 kHz

OFDM waveforms with increased subcarrier spacing are a candidate for 6G. Hexa-X Deliverable D2.3 Table 5-2 defines OFDM waveforms with subcarrier spacings of 1920 kHz and 3840 kHz [\\[3\\]](<https://www.mathworks.com/help/5g/ug/get-started-with-6g-exploration-library.html#mw_rtc_GetStartedWith6GExplorationLibraryExample_M_96C3D2CD>). Section 5.1.1 of the Hexa-X deliverable describes that OFDM symbols with increased subcarrier spacing are shorter in time, which facilitates reduced latency. Section 5.1.2.1.1 describes that wider subcarrier spacing improves the tolerance to phase noise, which is more severe at higher carrier frequencies. You can use the SubcarrierSpacing property of the pre6GCarrierConfig object to specify a subcarrier spacing greater than 960 kHz. For example, configure a carrier with a subcarrier spacing of 3840 kHz and 36 resource blocks. ##### Resource Grids Larger Than 275 Resource Blocks

At World Radiocommunication Conference 2023 (WRC-23), ITU agreed to assign a new band 6.425 - 7.125 GHz for the terrestrial component of the International Mobile Telecommunications (IMT) system [\\[4\\]](<https://www.mathworks.com/help/5g/ug/get-started-with-6g-exploration-library.html#mw_rtc_GetStartedWith6GExplorationLibraryExample_M_694BE197>). This band contains 700 MHz of spectrum and is a potential operating band for the next generation of IMT, which is IMT-2030 [\\[5\\]](<https://www.mathworks.com/help/5g/ug/get-started-with-6g-exploration-library.html#mw_rtc_GetStartedWith6GExplorationLibraryExample_M_777A3229>), also known as 6G. To evaluate the performance of a 6G candidate waveform occupying 700 MHz bandwidth and using 120 kHz subcarrier spacing, you need a number of resource blocks greater than 275. You can use the NSizeGrid property of pre6GCarrierConfig to create resource grids with more than 275 resource blocks. For example, configure a carrier with the largest number of resource blocks that can be allocated in a 700 MHz bandwidth by using 120 kHz subcarrier spacing and without exceeding a bandwidth occupancy of 0.9. The bandwidth occupancy is the ratio of occupied bandwidth to channel bandwidth. A larger bandwidth occupancy results in more capacity but requires better filtering to avoid emissions outside the channel bandwidth. ##### Extended Modulation Schemes

Higher-order modulation schemes, beyond 1024-QAM, are another candidate for 6G. You can use the Modulation property of the pre6GPhysicalChannelConfig object to specify a modulation scheme of '4096QAM' . Update the pre6GPhysicalChannelConfig object to use 4096-QAM modulation. ##### Further Exploration

6G Exploration Library for 5G Toolbox provides examples that you can further customize to explore 6G waveforms and related technologies. For example: * To explore the use of DFT-s-OFDM (Discrete Fourier Transform spread Orthogonal Frequency Division Multiplexing) and the impact of hardware impairments on candidate 6G waveforms with increased subcarrier spacing, see the [Measure Impact of Sub-THz Hardware Impairments on 6G Waveforms](<https://www.mathworks.com/help/5g/ug/measure-impact-of-sub-thz-hardware-impairments-on-6g-waveforms.html>) example. * To perform link-level simulations using candidate 6G waveforms with increased subcarrier spacing or increased number of resource blocks, see the [6G Link-Level Simulation](<https://www.mathworks.com/help/5g/ug/pre-6g-link-level-simulation.html>) example.
